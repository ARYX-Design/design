# ARYX logo

Chosen concept: **Facet** — a solid A split into violet and teal halves, with a custom-drawn ARYX wordmark.

| File | Use |
|---|---|
| `aryx-mark.svg` | Icon / avatar / favicon source (full color) |
| `aryx-logo-dark-bg.svg` | Horizontal lockup for dark backgrounds |
| `aryx-logo-light-bg.svg` | Horizontal lockup for light backgrounds |
| `aryx-mark-mono-white.svg`, `aryx-mark-mono-black.svg` | Single-color mark for stamps, print, watermarks |
| `concepts/` | The two unchosen concepts (Apex, Orbit) and the comparison sheet |

Colors: violet `#8f6bff` → `#5a3df0`, teal `#00f0c8` → `#00b3d6`, ink `#0a0a0f`.
The wordmark is stroke-drawn SVG, so it needs no font and renders the same everywhere.
