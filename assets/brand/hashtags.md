# ARYX — hashtags

No hashtag set guarantees a video goes viral: the platforms weigh watch time, replays and shares far more than tags. Hashtags mainly help the algorithm place a video with the right audience. Use 3–5 targeted tags per post, not 30, and check each tag's volume in the platform's search before posting. Current popularity was not verified.

## Per platform
- **Instagram Reels:** 3–5 tags in the caption; the first line of the caption matters more than the tags.
- **TikTok:** 3–5 tags; add one topic tag the viewer is likely to search.
- **YouTube Shorts:** `#Shorts` plus 2–3 topic tags; put the main keyword in the title.
- **LinkedIn:** 3–5 topic tags, no `#fyp` or `#viral`.
